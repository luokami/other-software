支持 Android 8.0 及以上，包含分类记账、借款与还款、汇总与明细、搜索、本机备份、隐私锁等功能。安装包无需联网使用。

1.3.0 已迁移到 Kotlin / Jetpack Compose + Room 原生框架。可直接覆盖 1.2.0，首次启动自动迁移旧账及设置。1.1.0 使用不同包名，需通过完整 JSON 备份导入。
