# 小店账本原生版 v1.3.0

这次将界面从 React / WebView 迁移到 Kotlin / Jetpack Compose，使用 Room 保存本机数据，完整离线使用。

- 保留分类记账、独立收入、借款与分次还款、汇总、按日明细、搜索、回收站和提醒。
- 原生紧凑表单适配输入法；状态栏安全区域、底部导航、开关和五档字号统一使用原生布局。
- 保留首次教程、隐私锁、后台自动锁定、JSON 备份恢复、CSV 导出及最近 7 个变化日期的本机自动备份。
- 从 v1.2.0 直接覆盖安装：包名与签名一致，首次启动原子导入旧账目、设置、密码和自动备份；迁移失败可重试，旧数据库保留，原桌面启动入口继续兼容。
- 从 v1.1.0 请先导出完整 JSON，再导入本版（该历史版本包名不同）。

Android 8.0 及以上。提醒仅在应用内检查。自动备份仍在本机，卸载前请导出 JSON 到应用外。
