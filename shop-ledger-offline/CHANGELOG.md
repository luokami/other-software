# 小店记账软件更新表

整理日期：2026年10月11日

## 版本规则

- **v1.x：大改。** 新增主要模块，或明显改变页面结构、录入流程、数据保存方式。例如 v1.8 → v1.9。
- **v1.x.x：小修补。** 在对应大改上调整文案、字段、尺寸、交互或修复问题。例如 v1.9 → v1.9.1 → v1.9.2。
- 每次大改后，小修补编号从 1 重新开始。v1.10 表示 v1.9 之后的下一次大改，版本号不是小数。

本表依据本次对话中你的意见，按提出顺序追溯整理。以下版本号是新编排的更新记录编号，不代表当时实际发布过同名安装包。前期图片属于设计方案；“你觉得还缺一些什么”属于建议讨论，单独标注，不分配发布版本。“继续任务”等执行指令不重复计为更新。

当前已交付 APK 的包版本仍为 **1.1.0**；按本表的需求演进分类，离线 APK 阶段对应 **v1.10**。本次仅整理文档，没有修改安装包版本号，也没有重新编译 APK。

## 最终规则对照

| 项目 | 后续确认的规则 |
| --- | --- |
| 收入入口 | 固定收入、额外收入；额外收入填写“是什么收入”“多少钱”。 |
| 支出项目 | 房租、蔬菜、米面、调料、肉类、礼品、工人工资、生活缴费、其他杂项；支持自定义项目管理。 |
| 分类表单 | 食品及生活缴费填写具体项目；工资填写人员、金额和备注；首页已选分类时不再重复选择。 |
| 首页 | 以记录入口为主，状态置顶，保护金额隐私。 |
| 字号 | 特小、小、标准、大、特大，默认标准；放大幅度较小，缩小幅度较大。 |
| 底部导航 | 首页、借款、记账汇总、收支明细、设置；保持紧凑。 |
| 借款 | 独立记录，不计入总收支；列表一级入口记还钱；支持部分还款和结清状态。 |
| 明细 | 今日、本月、本年、自定义时间；分类筛选与搜索；按日汇总，点击展开紧凑记录。 |
| 回收站 | 借款与收支回收站统一放在设置；删除先二次确认。 |
| 数据保护 | 本机自动备份开关、完整备份与恢复、账本导出、隐私锁；未解锁只可查看首页。 |
| 最终形态 | 安卓离线 APK，资源内置，数据保存在手机本地。 |
