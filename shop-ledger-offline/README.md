# 小店账本离线版 1.1.0

安卓 8.0 及以上；建议使用已更新的 Android System WebView。

本版本沿用网页版最新界面，包含收入/支出分类、借款与还款、汇总、按日明细、搜索、常填项、回收站、字体、浅色/深色、设备隐私密码、自动备份、JSON 恢复和 CSV 导出。

账本写入应用私有 SQLite 数据库；显示和密码设置位于本机 WebView 存储，自动备份位于本机 IndexedDB。页面和脚本内置到 APK，没有联网权限，没有账号登录或云同步。

## 从网页版迁移

1. 在网页版的设置 → 备份与恢复，导出“完整备份”JSON。
2. 安装 APK，打开设置 → 备份与恢复 → 恢复备份。
3. 选择 JSON，查看记录数量，确认恢复。

恢复前会在 SQLite 事务中保留完整保护备份，可在备份页“恢复前保护备份”恢复。系统文件保存器可导出到手机目录。开启隐私锁后，系统文件界面返回时可能要求先解锁，再继续导入。

自动备份保留最近 7 个有变化日期的备份，同日更新同一个备份。卸载应用或清除应用数据会删除本机数据，请定期导出完整备份。密码不随账本导出；请记住密码。

房租和工资提醒目前在打开账本时检查，没有后台定时推送。

## 构建

`npm install` 后运行 `npm run check`、`npm test`、`npm run build:apk`。

需要 Python 3、Java 17、Node.js 22 及以上。构建脚本在缺失时下载 Android 平台、构建工具和 Eclipse 编译器，页面构建阶段也需要安装的依赖；生成 APK 后使用不需要网络。

源码不包含现有签名密钥。开发者重新构建时默认生成新的签名密钥，只有使用原签名密钥才能覆盖更新已经安装的 APK。
