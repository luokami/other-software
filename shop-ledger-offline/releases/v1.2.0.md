# 小店账本新版 v1.2.0

- 新增首次使用教程，四步介绍记账、借款还款、收支查询、备份与隐私；支持跳过，并可在设置中重看。

- 教程适配小屏、横屏及特大字号，不会向账本写入演示数据。

## 安装与旧账迁移

原 v1.1.0 签名密钥已无法恢复。本次使用新的应用标识，桌面名称为“小店账本新版”，可与旧版并存，不能直接覆盖旧版。

1. 保留旧版，在旧版“设置 → 备份与恢复”导出完整 JSON 文件。
2. 下载并安装本页 APK，在新版导入该 JSON。
3. 核对账目和借款后，再自行决定是否保留旧版。隐私锁密码需重新设置。

支持 Android 8.0 及以上，安装后无需联网。旧版账目不会被新版读取或删除。
